# Архитектура системы «Учёт заявок Helpdesk»

## Выбранная архитектура: Layered Architecture

### Слои

1. **Presentation (CLI)** — командный интерфейс в main.py
2. **Service (Бизнес-логика)** — правила обработки заявок
3. **Repository (Данные)** — работа с БД
4. **Database** — SQLite

### Ответственности

| Компонент | Что делает | Чего НЕ делает |
| --------- | ---------- | -------------- |
| main.py (CLI) | Принимает команды, выводит результат | Не пишет в БД напрямую |
| services/ | Проверяет права, меняет статусы, SLA | Не знает о SQL |
| repos/ | Выполняет запросы к БД | Не принимает бизнес-решений |
| database | Хранит данные | Не содержит UI-логики |

### Поток данных

Пользователь вводит `create_request`
→ main.py вызывает service.create_request()
→ service проверяет категорию, роль
→ repo сохраняет в БД
→ main.py выводит "Заявка создана"
